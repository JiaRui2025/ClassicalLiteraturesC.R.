# 版式系统

一套「学术读物」的视觉语言：纸感底色、衬线正文、等宽元信息、赤陶点缀。目标不是漂亮，是**让读者相信这是可以认真读的东西**。

---

## 一、色板

| 变量 | 值 | 用途 |
|---|---|---|
| `--paper` | `#f3f0e9` | 页面底色（米白，模拟胶版纸） |
| `--paper-2` | `#faf8f3` | 卡片底（比纸略亮，制造「贴上去的纸片」） |
| `--paper-3` | `#e9e4d9` | 分隔区块底 |
| `--ink` | `#191714` | 正文（不是纯黑，留一点暖） |
| `--ink-2` | `#403a33` | 次级正文 |
| `--muted` | `#7d756a` | 图注、说明 |
| `--faint` | `#a89e90` | 元信息、单位 |
| `--rule` | `#d9d2c3` | 细分隔线 |
| `--rule-2` | `#c4baa7` | 强调线、悬停边框 |
| `--terra` | `#a8482a` | 赤陶：章号、标签、强调 |
| `--patina` | `#3f5f52` | 铜绿：第二强调（用于对照/否定项） |
| `--gold` | `#8a6a2f` | 金褐：第三强调（少用） |

深色结论区：底 `--ink`，文字 `--paper`，强调色提亮到 `#d98a63`（原 `--terra` 在深底上会闷）。

**三条纪律**：强调色最多三个，且每个只承担一种语义；正文绝不用纯黑纯白；分隔线永远 1px，不用阴影代替。

## 二、字体

```css
--serif: "Iowan Old Style","Palatino Linotype",Palatino,"Book Antiqua",Georgia,"Songti SC","Source Han Serif SC",serif;
--sans:  "PingFang SC","Hiragino Sans GB","Microsoft YaHei",-apple-system,"Segoe UI",Roboto,sans-serif;
--mono:  ui-monospace,"SF Mono",Menlo,Consolas,monospace;
```

| 用途 | 字体 | 字号 / 行高 |
|---|---|---|
| 大标题 | serif | `clamp(24px,3vw,36px)` / 1.2 |
| 章节「本章解决」 | serif | 19px / 1.7 |
| 正文 | sans | 16px / 1.75 |
| 图版标题 | sans 600 | 14px / 1.45 |
| 图版解读（中） | sans | 13.5px / 1.8 |
| 图版解读（英） | serif | 13.5px / 1.62 |
| 元信息 / 标签 | mono | 10–11px / 字距 .14–.2em，全大写 |

**英译用衬线、中文用黑体**——西文衬线在小字号下的可读性优于无衬线，中文则相反。这不是风格偏好，是字面密度决定的。

## 三、栅格

```
.wrap{max-width:1180px; margin:0 auto; padding:0 6vw}
```

- 内容宽 1180px，左右各留 6vw 呼吸。
- 章节头：`grid-template-columns:120px 1fr`（左罗马数字，右标题组）。
- 图版：`repeat(auto-fill,minmax(290px,1fr))`，间距 `34px 26px`。1440px 下自然成 3 列。
- 材料卡（结论区）：`repeat(auto-fit,minmax(230px,1fr))`，`gap:1px` + 父级底色做「发丝分隔」。

## 四、关键组件

### 图版卡 `.plate`

```
┌─────────────────────────┐
│ ┌─────────────────────┐ │  .frame  height:290px, 白底, padding 14px
│ │  [III-24]           │ │  .stamp  左上角编号，等宽小字
│ │      <img>          │ │  img: object-fit:contain（不裁切！）
│ └─────────────────────┘ │
│ Fig. III-24. Contour…   │  .cap-es 原文图注，斜体，--muted
│ 白云岩上的轮廓状剥落      │  .cap-t  中英标题，600
│ 解读正文…                │  .cap-d  中英解读
└─────────────────────────┘
```

三个不可动的设定：

1. **`.frame` 固定 290px** —— 图片比例各异，不固定高度就会瀑布流，行行参差。
2. **`object-fit:contain`** —— 图版是史料，不能裁切。宁可上下留白。
3. **原文图注在最上** —— 层级不能反：原文 → 译名 → 解读。

### 章节头 `.ch-head`

左侧 `120px` 放罗马数字（serif，`clamp(56px,8vw,104px)`，`--terra`），右侧三行：中/英标题（h3，两语叠放靠 `data-lang` 切换）、原文标题（斜体、`--muted`）、元信息行（页码 · 图数 · 一句话定性）。

### 「本章解决」 `.settles`

```
本章解决 │ 把「石头为什么会坏」从经验判断，重写为一个可分解的科学问题…
```

左侧等宽小标签（`--terra`），右侧 19px 衬线，左边一条 1px 竖线。**这一块必须放在正文之前**——读者先拿结论，再决定读不读下去。

### 「岩芯」章节导航

左栏竖条，每一段的高度 ∝ 该章页数。滚动时当前章高亮（IntersectionObserver 或滚动位置比较）。

比目录好在：一眼看出全书的分量分布（某章 100 页 vs 某章 12 页），读的时候知道自己在哪。

### 结论区 `.verdict`

整块深色（`--ink` 底）。上半是材料卡网格（每张卡：名称、编号、主导机制、孔隙率、典型病害、耐久性条），下半是排序列表（序号 + 名称 + 进度条）。

**这一区不是复述**，是给出可带走的判断：排序、权衡、代价。没有结论的精读网页只是加长版目录。

### 灯箱 `#lb`

点击 `.frame` 打开，显示大图 + 编号 + 当前语言的图注；`←/→` 翻页，`Esc` 关闭。所有图版共用一条 `allFigs` 数组，翻页跨章节连续。

## 五、交互

| 交互 | 实现 | 注意 |
|---|---|---|
| 语言切换 | `document.documentElement.dataset.lang = 'zh'\|'en'` | 只改一个属性，CSS 负责显示隐藏；不要在 JS 里替换文本 |
| 进场动画 | `IntersectionObserver` 加 `.rv` → `.in` | 必须支持 `prefers-reduced-motion`，否则截图工具截到半透明 |
| 阅读进度 | 顶部 2px 条，`scrollTop / (scrollHeight - innerHeight)` | — |
| 章节高亮 | 滚动时比较各 section 的 `offsetTop` | 用 `requestAnimationFrame` 节流 |
| 图片懒加载 | `loading="lazy"` | 80 张图版必须懒加载，否则首屏卡 |

## 六、响应式

单断点 `max-width:900px`：

- `.ch-head` 改单列（罗马数字移到标题上方）。
- `.plates` 因 `auto-fill` 自然降到 2 列 / 1 列。
- `.pillars` 两栏改单栏，去掉竖分隔线。
- 顶部导航隐藏章节名，只留标题与语言按钮。

---

## 七、不要做的事

- 不要用纯白底 `#fff` 做页面底色——刺眼，且与扫描图版的白不协调。
- 不要给图版加圆角、阴影、边框装饰——它们是文献，不是卡片。
- 不要用 `auto-fit` 排图版网格——会在某些宽度下留空格。
- 不要在长区块上用渐变背景——滚动时会露出接缝。
- 不要给正文加 `letter-spacing`——中文会散架。
